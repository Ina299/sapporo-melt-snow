広域道路と事業者別経路（2026-09-08）

最新の事業者配車は広域の事業者・車両割当へ更新済み。 以下の八軒に限定した事業者別試算は旧版の記録です。主画面では42万1,029方向区間を4社で分担します。

広域の被覆計算

OSM車道を南42.75・西140.95・北43.26・東141.55の矩形で取得した。緯度帯5件を重複除去して39,910 waysを取得。行政界による切抜きではなく、札幌市域と周辺を含む。対象種別は primary / secondary / tertiary / unclassified / residential / living_street と主要リンク道。高速道路・trunk・構内道路・歩道などは対象外。市管理道路・公式除雪対象路線との照合は未実施。

各成分の有向郵便配達人問題を最小費用流で解き、閉路の連続性・合法方向・対象区間の被覆を検証。孤立した成分へ実車両を配置できる保証はない。全市で実行できる一つの配車計画ではない。成分をつなぐため架空の道路を追加していない。道路形状点間の区間を数えており、道路の「本数」ではない。往復道路は方向を別に数える。

取得クエリ・日時・SHA-256は data/city_roads_source.json と data/raw/city/band*_source.json。右左折禁止relationは今回未取得で、制限ゼロを意味しない。道路のway単位accessとonewayのみ反映。位置・機種・車幅・道路幅・時間規制等の現場照合が必要。

事業者別の実証経路

台数・所在地が公表されている4社を対象とした。各社が独立に、同じ八軒の1,236方向区間を担当する比較である。各社の実契約地区・共同配車・市全域の担当割当ではない。各社の所在地を広域道路網へスナップし、作業区間までの往復経路を接続した。地図の灰色点線は住所代表点から道路接続点までの未確認の接続で、走行時間・距離には加算していない。

ダンプ・大型ロータリ・小型ショベルを同じ除雪車として混算していない。ただし含めた機種も同じ作業速度の仮定で、除雪装備・当日の配備・対象道路への適合性は未確認。公表上限は稼働台数ではない。

既存の実証閉路を各社の往復回送が短い開始点へ回転し、作業・回送時間に応じて連続分割。分割の両端と所在地道路ノードを広域道路上の最短時間経路で結ぶ。各車両は同じ会社の出発道路ノードへ戻る。作業8km/h・回送20km/h。出発位置・分割の同時最適化ではなく近似解。実証道路は従来スナップショットを保持し、広域取得の接続網へ統合している。

全30シナリオで被覆・経路連続・合法方向・所在地道路ノードへの帰着を検証した。車両別の距離・時間と、走行順に作業/回送を分けたGeoJSONは data/processed/contractor_routes.json に保存。全市域の閉路の詳細は data/processed/city_routes.json。
