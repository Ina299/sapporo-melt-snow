# DC候補地の因子別スクリーニング（2026-09-09）

候補地の選定を「工業・物流地区を人手で挙げて、受電・IXを後から一律評価する」段階から、**雪の発生地からの運搬距離を定量化し、受電・IX・用地と混ぜずに並べる**段階へ進めた。点数化して合計せず、因子ごとに列を分ける。用地・受電・IXの確認状況は[立地検証](dc_feasibility.md)、地域配置の考え方は[分散案](regional_melting.md)。再現：`python scripts/build_dc_siting.py`、成果物 `data/processed/dc_siting.json`・`dc_siting_cells.csv`、画面は「工業・物流用地にDCと融雪を併設する」節の因子表と地図の「路上降雪メッシュ」。

## 雪の供給側：1kmメッシュの路上降雪

配車モデルの作業対象（札幌市内の車道、未舗装・私道等を除く）を1kmメッシュに集計し、道路種別ごとの仮定除雪幅を掛けて道路面積を出す。同じ道路の往復方向は二重計上しない。降雪は市内13観測点の2025年度（2025-11-01〜2026-04-10、161日）の季節合計と日量95パーセンタイルを、メッシュ中心から最寄りの観測点で与える。新雪密度100kg/m³。

| 入力 | 値・扱い |
|---|---|
| 対象車道 | 6,435km、599メッシュ。道路面積4,382ha |
| 除雪幅の仮定 | primary 12m、secondary 11m、tertiary 9m、unclassified・residential 6m、living_street 5m |
| 排雪率 | 50%。道路上の降雪のうちトラックで運び出す割合の仮定。候補地の順位には影響せず、トン数とMW換算だけに影響する |
| 距離 | 直線×迂回係数1.3。道路距離・橋・冬季渋滞は未反映 |
| 観測点の座標 | 地名・区役所住所の国土地理院住所検索。センサー位置ではない。北区(太平)・あいの里は複数候補のうち先頭を採用 |

結果は季節1,171万t（排雪率50%換算）、平均日量72,732t、95%日量418,380t。20MWのDC1か所（3,531t/日）は平均日量の4.9%。95%日量を当日中に全量融雪するには2,370MW相当が要るので、DC融雪は貯雪で平準化した一定量の処理と位置づける。トン数は仮定幅と排雪率に比例する近似で、実排雪量の推計ではない。

## 候補地の組合せ：季節トン·km

各メッシュを最寄り候補地に割り当て、候補7地区から1〜4地点を選ぶ全組合せを季節トン·kmで並べた。

| 拠点数 | 最小トン·kmの組合せ | 平均運搬距離 | 受持ち割合 |
|---|---|---:|---|
| 1 | DC6 山鼻 | 11.37km | 100% |
| 2 | DC3 大谷地・北野＋DC4 新川・発寒北 | 7.98km | 53%／47% |
| 2（次点） | DC3 大谷地・北野＋DC7 宮の沢 | 8.02km | 49%／51% |
| 3 | DC3＋DC4＋DC6 山鼻 | 6.57km | 32%／38%／30% |
| 3（次点） | DC2 真駒内・石山＋DC3＋DC4 | 6.70km | 18%／38%／44% |
| 4 | DC2＋DC3＋DC4＋DC6 | 6.08km | 12%／31%／38%／19% |

読み方。2地点目までで平均運搬距離は11.4→8.0kmと大きく縮み、3地点目で6.6km、4地点目で6.1kmと効果は減る。DC1 手稲山口・前田は単独平均20.3km、10km圏の雪が12%で、運搬の面では最も不利。市外への搬出を市内処理に置き換える政策目的で残す場合は、この不利を明示した上で判断する。DC5 東米里は最良2地点に加えたときの削減が525万t·kmで、DC6 山鼻（1,655万）・DC2 真駒内（1,499万）より小さい。

用地の列は候補地代表点から半径1.5kmのOSMデータ。札幌のOSMは土地利用（landuse）がほとんど付いておらず、住宅比率は全候補で1%未満になるため使えない。代わりに建物種別（building タグのうち house・apartments 等を住宅系、industrial・warehouse 等を工業系とし、`yes` は除く）の割合と、住宅街路（highway=residential）の延長密度で住宅地かどうかを読む。工業系区画は landuse=industrial・railway 等のポリゴンで3ha以上のもの。用途地域（法的な立地可否）、売地の有無、所有者、ハザードは含まない。

## 因子を混ぜずに読むと

- **運搬だけなら** DC3＋DC4 の2地点が最良で、3地点目は DC6 山鼻。ただし山鼻は住宅系建物84%で工業区画がなく、受電は要照会。運搬の利点は用地の制約と相殺されず、公共用地の転用を政策として扱うかどうかで決まる。
- **受電と用地が揃うのは** DC3・DC4・DC7。187kV系送電線が2km以内で公開区分が50〜99MW、3ha以上の工業系区画がある。DC3の大区画は貨物ターミナルの鉄道用地で、工業団地ではない点に注意。
- **DC2 真駒内・石山**は3地点目の次点（削減1,499万t·km）だが、工業区画がなく受電も要照会。南区の雪を受ける役割は運搬の数字で裏付けられたので、次は公共用地・既利用地の区画探索が課題になる。
- **DC5 東米里**は運搬の削減が小さく、周辺建物は少ない（種別付き建物が少数）。既存の東部融雪機能との連携という別の役割で評価する。
- **DC1 手稲**は運搬で最も不利。石狩新港西地区への市外搬出の置き換えという政策目的を数値化しないと残す理由が立たない。

## 限界と次の段階

- 距離は直線×1.3。道路距離への置き換えは Actions 上で配車グラフを使えば可能。シフト小区域ごとの重心からの距離に置き換えると、実際の作業区域からの運搬になる。
- 雪量は仮定幅×観測降雪の近似。市の実排雪量（区別の運搬量）が得られれば校正する。
- 既存融雪施設（`candidates.json` の公表能力）を固定の受入先として置き、不足分だけを新設で受ける計算は未実施。
- 用途地域（国土数値情報A29）、洪水浸水想定（A31）、土砂災害警戒区域（A33）は未取得。区画候補が出た段階で除外条件として使う。
