# 事業者所在地・機械数の照合（2026-09-08）

現在の4地点を、機械配備が確認された出動拠点として扱うことはできない。公開住所は確認したが、配備数と出動場所の組合せは4社とも不明。確認済みが0件という意味であり、配備台数が0台という意味ではない。

採用した30台は実配備でも稼働可能な上限でもない。ダンプ・ロータリ・小型ショベルの除外は現行の単純な路面作業モデルでの選択であり、現場で使えないという判定ではない。採用機種も装備・車幅・運転者・契約拘束を確認していない。異なる機種を同じ作業速度8km/hで扱う仮定も残る。

東洋・鹿島・KRSの台帳は会社一覧から関連機種のみを抜粋しており、全車両の総数ではない。サツイチは土木事業部ページの台数であり、会社全体の台数と記した説明を訂正した。同社には川下の札幌営業所（運輸・重機）と流通センター支店もあるが、土木部門の車両がそこにあるとも断定できない。

4地点とも国土地理院の検索結果は地番まで（1080、1775、708、577）で、公開住所の枝番（29、5、3、87）まで一致していない。単一候補でも敷地・出入口の精度は保証されない。従来の点を移動せず、住所代表点による仮想出発地として表示する。サツイチのアイコンの表示位置も補正しない。

したがって現在の経路・88時間等は「この代表点にこの台数を集中配備した場合」の比較に限る。実際の会社の担当区域や運用可能な計画を示していない。基礎条件が変われば区域境界・回送距離・必要時間を再計算する必要がある。

実配車へ進めるには、会社IDと別の拠点IDを設け、各拠点の出入口座標、機種別配備、当日の使用可能数、装備、担当工区、運転者を対応付ける必要がある。不明値はnullを維持し、会社保有数から各拠点へ自動転記しない。
