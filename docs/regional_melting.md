# 南側へのDC融雪拠点の分散案（2026-09-08）

提案は、DC4（新川・発寒）とDC5（東米里・米里）で既存融雪機能との接続・増強を調べながら、南西・南東に新設DCと融雪設備を組み合わせる地区を探すこと。候補地は札幌市内に限定し、雪の発生地に近い複数拠点への分散を比較する。市の配置案で手稲北地区・北区西地区が使う石狩市内の雪堆積場は現状の搬出先として記録するが、新設DCの候補には含めない。中央部・すすきの周辺の一等地は新設用地の探索対象から外す。

## 北側への偏りをどう判断するか

[札幌市の雪堆積場等配置一覧（案）](https://www.city.sapporo.jp/kensetsu/yuki/jigyosha/documents/3-taisekijoitiran.pdf)の取得済み2026年度資料では、南区と清田区の雪処理施設欄は空欄。南区には石山大橋・五輪大橋・藻南橋周辺等、清田区には真栄地区・北野橋周辺等の雪堆積場が掲載されている。この範囲では、南側の融雪機能を検討する理由がある。配置案であり、供用状況や市内全施設の不存在を証明する資料ではない。[確認画像1](../data/raw/procurement_2026_3-taisekijoitiran_0.png)・[確認画像2](../data/raw/procurement_2026_3-taisekijoitiran_1.png)。

現在の地図の7点はDC排熱との接続を調べるために選んだ施設で、市内の全雪処理施設ではない。同じ配置案には月寒公園、アクセスサッポロ、伏古公園北等も載る。さらに東部は供用計画、発寒は現行稼働未確認を含む。「南側には雪を処理する場所がない」「北側の能力が何％」とはまだ言えない。施設種別、稼働、受入対象、日処理量、地区別排雪量を揃えた評価が必要。

## 比較する6つの役割

| 方面・探索地区 | 受け持つ雪の仮説 | 検討する設備 | 採否を左右する条件 |
|---|---|---|---|
| DC1：手稲山口・前田方面 | 手稲・新川側 | 手稲北部でDC＋融雪槽＋一時貯雪。市外（石狩新港西地区）への搬出を市内処理へ置き換える比較 | 新川下流・沿岸低地の洪水・内水・津波、地盤、受電・回線、住宅地からの搬入経路 |
| DC4：新川・発寒 | 西・北側 | 新設DCと新川・発寒方面の既存融雪機能との接続・増強 | 既存熱源との重複、追加投雪・排水能力、隣接用地、実配管距離 |
| DC6：円山・宮の森方面（参考） | 中央区西部 | 用地が見つかれば小規模DC＋融雪槽。現状はOSM上にまとまった工業・遊休地がない | 用地の有無が唯一の関門。受電・IX条件は[検証書](dc_feasibility.md)の一律評価で比較可能 |
| DC5：東米里・米里 | 白石・厚別側 | 新設DCと東部・厚別方面の融雪機能を比較 | DC5の地区代表点と各施設は別地点。東部の供用条件、敷地・配管・排水余力 |
| DC2 南西：真駒内・石山方面 | 南区、中央区南側 | 幹線道路に接続できる既利用地でDC＋独立融雪槽＋一時貯雪 | 住宅地回避、橋の横断・冬季渋滞、洪水・斜面、受電・異経路回線・排水 |
| DC3 南東：大谷地流通業務団地・北野方面 | 清田・豊平東側、厚別南側 | 物流用地の更新に合わせたDC＋融雪・貯雪 | 現物流機能との両立、用途・用地、住宅への搬入影響、DC5との運搬時間比較 |

南西・南東は本検討の探索仮説であり、取得可能な区画の発見ではない。地区代表点を新しい建設候補地として確定せず、まず用地を探す。河川敷の雪堆積場の存在をDC建設用地の根拠にしない。

石山・真駒内は住宅地が多い。南西を工業地区と一括して扱わず、条件に合う既利用地が見つからなければこの案を見送る。駒岡方面を代替探索する場合も、[既存の清掃工場余熱利用](https://www.city.sapporo.jp/seiso/gomi/netu.html)とDC熱を重ねて便益計上しない。

南東の用地探索は、[大谷地流通業務団地高度化ビジョン](https://www.city.sapporo.jp/keizai/ooyachi/koudokavision.html)が示す流通機能の維持・更新の文脈で検討する。更新方針は空地、売地、DC用途の許可、安価な土地の証拠ではない。東米里は清田の雪を受けるには北寄りなので、大谷地・北野案との実道路比較が必要。

## 同じDC総容量で集中と分散を比べる

例えば追加IT容量20MWを1地点に置く案と、南西10MW＋南東10MWの2地点に置く案を比較する。既存の熱モデルと同じ稼働率90％・回収率80％等なら、合計の熱上限はどちらも約3,531t/日。分散しただけで融雪熱量は増えない。各10MW地点は約1,765t/日、8t積みで約221便/日、同じ搬入条件なら3レーンが目安。これは南側に20MWを配分する感度例で、DC容量の決定ではない。

仮に各便の往復が10km短くなれば、約441便/日・燃費2km/Lで軽油約2,207L/日の削減になる。実道路による結果ではなく、満量搬入時の感度計算。分散で増える受変電・回線・冷却・融雪設備の費用と対比し、実際の雪到着量が少ない日も含めて判断する。

既存槽の公表能力にDCの熱上限をそのまま足さない。追加能力は、熱、投雪、排水、一時貯雪、搬入の各余力で制限される。下水熱や焼却余熱の置換だけなら、総処理量は増えない場合もある。

次の計算には、地区別の搬出雪量・積込点、各施設の時間別受入量、ダンプの積載量・出発点、搬入時間帯が必要。現在の除雪車による全道路被覆経路は排雪ダンプの運搬経路を計算したものではない。受入容量と待機を含む運搬先割当を別に組み、現状、DC4・5増強、南西追加、南東追加、両方追加を同じ総IT容量・雪量で比較する。現在の88時間等をこの案の短縮効果には転用しない。
